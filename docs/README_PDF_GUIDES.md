# PDF Lab Guides

This directory should contain the following PDF documents:

## LAB_GUIDE.pdf
**Status:** To be created by instructor

Complete step-by-step lab manual with:
- Detailed setup instructions
- Screenshot walkthroughs
- Exploitation procedures
- Post-exploitation techniques
- Defensive countermeasures
- Assessment rubrics

**Suggested page count:** 40-60 pages

---

## INSTRUCTOR_GUIDE.pdf
**Status:** To be created by instructor

Teaching notes and tips including:
- Lesson plans
- Common student issues
- Grading guidelines
- Discussion topics
- Security awareness points
- Additional resources

**Suggested page count:** 10-20 pages

## Creating the PDF Guides

If you're an instructor creating these guides, consider including:

### LAB_GUIDE.pdf Content:
1. **Introduction**
   - Lab objectives
   - Prerequisites
   - Safety warnings

2. **Environment Setup**
   - VirtualBox installation
   - Vagrant installation
   - Lab setup walkthrough

3. **Network Configuration**
   - IP addressing
   - Host-only networking
   - Connectivity testing

4. **Vulnerability Background**
   - CVE-2010-2883 explanation
   - Buffer overflow concepts
   - Adobe Reader security history

5. **Exploitation Walkthrough**
   - PDF generation with Metasploit
   - Listener configuration
   - Payload delivery
   - Shell interaction

6. **Post-Exploitation**
   - System enumeration
   - File operations
   - Privilege escalation attempts
   - Persistence techniques

7. **Defensive Measures**
   - Security controls review
   - Patch management
   - Detection techniques
   - Incident response

8. **Assessment**
   - Lab questions
   - Practical exercises
   - Proof of exploitation requirements

9. **Appendices**
   - Metasploit reference
   - Troubleshooting
   - Resources

### INSTRUCTOR_GUIDE.pdf Content:
1. **Course Integration**
   - Where this lab fits in curriculum
   - Timing and scheduling
   - Prerequisites check

2. **Preparation**
   - Test environment setup
   - Hardware requirements
   - Student preparation

3. **Facilitation Tips**
   - Common questions
   - Demo techniques
   - Pacing guidance

4. **Assessment**
   - Grading rubric
   - Expected outcomes
   - Red flags

5. **Troubleshooting**
   - Common technical issues
   - Network problems
   - VM failures

6. **Discussion Topics**
   - Ethics
   - Legal issues
   - Career paths
   - Real-world applications

7. **Extensions**
   - Advanced challenges
   - Additional exploits
   - Blue team exercises

## Tools for Creating PDFs

Recommended tools:
- **Markdown + Pandoc:** Write in Markdown, convert to PDF
- **LaTeX:** Professional formatting
- **Microsoft Word:** Export as PDF
- **Google Docs:** Easy collaboration
- **Typora:** Markdown editor with PDF export
